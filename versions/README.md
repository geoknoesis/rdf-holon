# Release snapshots

Each `versions/<version>/` directory holds the frozen artifacts of one RDF-H release, as tagged in
this repository: the vocabulary `rdfh.ttl` and the RDF-H, Turtle-H, and SPARQL-H documents. The
version IRI `https://w3id.org/rdf-h/<version>` is to resolve to that directory, with `rdfh.ttl` for
RDF clients. The editor's drafts at the repository root may be newer than any snapshot.
